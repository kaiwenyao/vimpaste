# VimPaste 隐私说明

VimPaste 是一个纯静态、无后端的浏览器工具。隐私是产品的功能，而不是附加说明。

## 数据流

- **编辑、语言识别、占位符标记、语法高亮、复制全部在浏览器本地计算**。本项目**没有后端服务器**，没有账号系统，没有任何第三方分析、广告、远程字体或上报服务。
- 编辑内容**不会**写入 URL、sessionStorage、IndexedDB、Service Worker 缓存、日志或错误报告。
- 唯一涉及编辑内容的持久化是**可选的粘贴历史**（见下节）：仅写入本浏览器的 localStorage，**不上传、不进入任何网络请求**。
- 复制仅在用户主动操作时调用浏览器 Clipboard API，内容只进入系统剪贴板。

## 本地持久化的数据

### 1. 偏好设置（键 `vimpaste.prefs.v1`，非敏感）

| 字段             | 含义                                     |
| ---------------- | ---------------------------------------- |
| `editorMode`     | 编辑器键位模式（vim / standard / emacs） |
| `fontSize`       | 编辑器字体大小                           |
| `hintDismissed`  | 首次使用提示是否已关闭（布尔）           |
| `theme`          | 颜色主题（`dark`/`light`/`contrast`）    |
| `historyEnabled` | 粘贴历史开关（布尔，默认 `true`）        |

### 2. 粘贴历史（键 `vimpaste.history.v1`，默认开启）

- **保存时机**：内容停止编辑约 1.5 秒后自动保存快照；点击「复制」或切换历史条目时立即保存。
- **保存内容**：编辑器文本、首行派生的标题、识别的语言、创建/更新时间。只存在本浏览器 localStorage。
- **上限**：最多保留最近 30 条，单条内容超过 10 万字符不保存；存储容量不足时从最旧的条目开始丢弃。
- **恢复**：在历史面板点击条目即可重新载入编辑器。
- **控制权**：面板中可删除单条、二次确认清空全部；关闭「自动保存」会立即清空所有历史并停止写入。
- **风险提示**：localStorage 按浏览器 Profile 隔离，但本机共用电脑/浏览器账号的人可以读到这些内容。处理过敏感 Token 后，建议手动清空历史。

### 3. 不保存的内容

关闭粘贴历史（或清空后）时，编辑内容只存在于当前标签页的内存中，刷新或关闭页面后立即消失。偏好键中永远不含编辑内容。

## 网络请求范围

应用加载自身静态资源（HTML / JS / CSS / 图标 / manifest / Service Worker），除此之外不发起任何网络请求。生产构建注入了内容安全策略（CSP），将脚本、连接、资源限制为同源。

## 边界说明

- 剪贴板是操作系统层面的共享资源：浏览器扩展、剪贴板同步工具（如某些输入法或云剪贴板）可能读取你复制的内容，这不在任何网页应用的控制范围内。
- 若部署平台（如 GitHub Pages）在应用之外另有日志或统计，属于平台自身行为，与本应用无关。
