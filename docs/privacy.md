# VimPaste 隐私说明

VimPaste 是一个纯静态、无后端的浏览器工具。隐私是产品的功能，而不是附加说明。

## 数据流

- **编辑内容只存在于当前标签页的内存中**。语言识别、占位符标记、语法高亮、复制全部在浏览器本地计算。
- 本项目**没有后端服务器**，没有账号系统，没有任何第三方分析、广告、远程字体或上报服务。
- 编辑内容**不会**写入 URL、localStorage、sessionStorage、IndexedDB、Service Worker 缓存、日志或错误报告。
- 刷新或关闭页面后，编辑内容立即消失。
- 复制仅在用户主动操作时调用浏览器 Clipboard API，内容只进入系统剪贴板。

## 唯一持久化的数据

浏览器 localStorage 中仅保存三个**非敏感偏好**（键 `vimpaste.prefs.v1`）：

| 字段            | 含义                                  |
| --------------- | ------------------------------------- |
| `vimEnabled`    | Vim 模式开关状态（布尔）              |
| `hintDismissed` | 首次使用提示是否已关闭（布尔）        |
| `theme`         | 颜色主题（`dark`/`light`/`contrast`） |

编辑内容永远不会进入该键或任何其他存储。

## 网络请求范围

应用加载自身静态资源（HTML / JS / CSS / 图标 / manifest / Service Worker），除此之外不发起任何网络请求。生产构建注入了内容安全策略（CSP），将脚本、连接、资源限制为同源。

## 边界说明

- 剪贴板是操作系统层面的共享资源：浏览器扩展、剪贴板同步工具（如某些输入法或云剪贴板）可能读取你复制的内容，这不在任何网页应用的控制范围内。
- 若部署平台（如 GitHub Pages）在应用之外另有日志或统计，属于平台自身行为，与本应用无关。
